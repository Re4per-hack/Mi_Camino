Podemos tene runa API endpoint de esta forma:

- `https://testpage.com/api/users/juan`

Pues podemos ir devolviéndonos en rutas para encontrar documentación, probar con todo lo siguiente:

- `http://testpage.com/api/users/`
- `http://testpage.com/api`

También es importante tener en cuenta de que probablemente la información se encuentre con el método GET, pero no debemos descartar los demás.
