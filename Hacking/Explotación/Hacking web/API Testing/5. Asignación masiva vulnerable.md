A continuación está el codigo vulnerable del framework que mantiene la pagina web:

Específicamente aquí podemos ver lo que se conoce como "modelo", que es una especie de plantilla para definir los campos que el usuario podrá llenar:

Ahora veremos como tal el código que permite explotar esta vulnerabilidad:


```java
@RequestMapping(value ="/addUser", method = RequestMethod.POST) // se va a ejecutar cuando llegue un POST

public String submit(User user) { // Función "submit" que define el objeto "user" con los atributos enviados por el cliente y se acomodan según el prototipo visto antes

	userService.add(user); // se actualizan los campos de en la base de datos
	return "successPage";
}
```

La vulnerabilidad esta en que en vez de solo permitir que el usuario pueda editar atributos especificos, el usuario puede definir cualquier atributo del objeto, este objeto es posteriormente enviado a la base de datos o utilizado en otra parte de la aplicación, permitiendo una especie de envenenamiento
