# Instalación

Esta version de SharpHound tiene una compilación de Any CPU, lo que significa que no importa la arquitectura, va a funcionar de igual manera

```ruby
sudo apt install sharphound
# Esto crea un archivo llamado sharphound.exe en /usr/share/sharphound/
```
