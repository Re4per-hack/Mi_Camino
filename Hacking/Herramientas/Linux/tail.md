Esta herramienta muestra las ultimas líneas de una salida de comandos:, usaremos de ejemplo el siguiente archivo:

```
Juan - 17 años
Pablo - 13 años
Silvia - 17 años
Margarita - 30 años
Steven - 20 años
Eddy - 17 años
```

Para mostrar únicamente la ultima línea:

```shell
cat nombres.txt | tail -n 1
```

El resultado seria:

```
Eddy - 17 años
```
