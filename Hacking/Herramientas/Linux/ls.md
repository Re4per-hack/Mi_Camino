El comando ls nos permite ver los archivos en el directorio actual o en un directorio especifico, además, con este comando podemos ver archivos ocultos, permisos de carpetas y archivos, ver la fecha de creación, el usuario creador del archivo/carpeta:

```shell
ls -l // Nos muestra mas informacion sobre cada archivo
ls -a // Nos muestra los archivos ocultos
ls -la // Es una combinacion de -l y -a
```
