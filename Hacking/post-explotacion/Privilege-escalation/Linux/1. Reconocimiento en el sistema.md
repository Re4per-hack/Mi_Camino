
# sudo -l 

### Lectura de sudo -l 

```shell 

$> sudo -l 

Matching Defaults entries for jp on parrot:
env_reset, mail_badpass, secure_path=/usr/local/sbin\: /usr/local/bin :/usr/sbin\ :/usr/bin\:/sbin\:/bin, use_pty

User jp may run the following commands on parrot:
(ALL : ALL) ALL
(ALL) ALL

```

- ***(ALL : ALL) ALL***

El primer `ALL` → significa que puede ejecutar comandos como **cualquier usuario**.
El segundo `ALL` → significa que puede ejecutar comandos como **cualquier grupo**.
El último `ALL` → significa que puede ejecutar **cualquier comando**.

- ***(ALL) ALL***

Esta es otra forma de escribirlo (dependiendo de la versión de `sudo`).  
Significa lo mismo: **puede ejecutar cualquier comando como cualquier usuario**.

### Ejecutables con sudo

Hay varios ejecutables del sistema de los cuales si tenemos permisos con sudo podemos aprovecharnos, para ver que podemos hacer con cada uno de estos ejecutables en caso de tener la opcion de usar sudo, podemos revisar la siguiente pagina [CTFOBins](https://gtfobins.github.io/)
Para listar los ejecutables que podemos usar con sudo podemos usar el siguiente comando:

```shell
sudo -l 
```
