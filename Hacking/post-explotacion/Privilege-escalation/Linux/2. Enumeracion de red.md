
# ==IP / Subnet==

Para ver la IP y subnet a la que pertenecemos, o incluso ver las interfaces de red podemos usar diferentes comandos:

- `ifconfig`

- `ip a`


#  ==Ver Puertos internos abiertos==

Para revisar los puertos que estan abiertos de forma interna, podemos usar el siguiente comando:

```ruby
netstat -tulnp 
```


## ==Enrutamiento ARP / IP==

para ver el enrutamiento de IPs vamos a usar el siguiente comando:

- `ip route`

Y para ver las enrutaciones de arp vamos a usar lo siguiente:

- `arp -a`
