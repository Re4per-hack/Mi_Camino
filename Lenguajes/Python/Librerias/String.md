String es una librería que nos ofrece una variedad de caracteres que nos permitirán crear ciertos scripts, desencriptaciones, etc... :

```python
import string

letrasMinusculas = string.ascii_lowercase
letrasMayusculas = string.ascii_uppercase
todasLetras = string.ascii_letters
numeros = string.digits
todosCaracteres = string.printable
# Etc...
```
