Las variables son un espacio que podemos usar para almacenar datos y luego manejarlos, para definir variables es tan simple como la siguiente forma:

```shell
variable="Hola"
```

La forma en la que podemos llamar variables es  usando un signo de dólar antes del nombre de la variable, aquí un ejemplo imprimiendo el contenido de esa variable en pantalla

```shell
echo "$variable mundo"
```

Es importante poner esta variable en comillas dobles y no en comillas simples, ya que cuando se usan comillas simples no se interpreta.

Así como en cada lenguaje hay diferentes tipos de datos, algunos de ellos son:

```shell
cadena="Hola"
boolean=true
int=2
array=(item1 item2 item3 item4)
```
